# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- `constellation demo` and a "Try the demo vault" button: the full pipeline runs offline on a bundled 15-note vault with canned model output, so no API keys are needed.
- `docs/DESIGN.md`: design decisions, trade-offs and known limitations.
- CI: pyright (basic), `ruff format --check`, a coverage summary, the offline demo, and a build and test job for the Obsidian plugin.
- `.pre-commit-config.yaml`, a release workflow that attaches the sdist and wheel to GitHub releases, issue and PR templates, `CONTRIBUTING.md`.
- README screenshots, regenerated by `scripts/capture_screenshots.py`.

### Changed
- `AgentState` is `total=False`, and a few annotations were narrowed so the codebase type-checks cleanly. No behaviour change.

## [0.2.0] - 2026-10-18

### Added
- Native Obsidian plugin (`obsidian-plugin/`): a TypeScript port of the pipeline using `requestUrl`, a JSON vector index with cosine search, `vault.process()` writes, a live side panel, preview diffs and undo. Its section-rewriting rules are pinned to the Python behaviour by a parity fixture.
- Pre-write backups with `--list-backups` / `--restore`, a `--strip` command, and a per-vault run lock.
- Backlinks, frontmatter tags, Ollama providers for local-only runs, a run report with token and embedding usage, extraction checkpoints that survive crashes, and `--watch` mode.
- Folder exclusions, a per-note link cap, link annotations, and new CLI flags.
- `pyproject.toml` packaging with a `constellation` console script, bounded dependencies, ruff, CI on Python 3.11–3.13, and offline end-to-end tests.
- Redesigned Streamlit UI: tabs, a live stage tracker, an interactive graph, history and undo, and a dark theme.

### Changed
- Capped links are ranked by score (best similarity plus a bonus per supporting concept pair) instead of alphabetically.
- Preview runs no longer write the index, and UI options persist across reruns.

### Fixed
- The FAISS index is persisted without pickle, and a legacy `index.pkl` is never loaded. An embedding manifest prevents mixing vectors from different models.
- Notes that failed extraction are retried on the next run instead of being marked done. Links to deleted or renamed notes are removed.
- Restoring a backup takes the vault lock.

## [0.1.0]

### Added
- LangGraph pipeline: concept extraction and verification, FAISS-backed relationship extraction and verification, and a writer for `## Tags` / `## Related Links`.
- Content-hash incremental cache, atomic temp-file writes that preserve hand-written text, API key rotation with backoff, and a structured-output retry loop for Groq.
- Streamlit dashboard with live logging and a headless CLI.
