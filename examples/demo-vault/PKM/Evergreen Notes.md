# Evergreen Notes

Andy Matuschak's term for notes that are written and refined over time, to
accumulate insight rather than just capture information.

- Evergreen notes should be **concept-oriented**, not organised by source or
  project, so the same idea can be reused across many projects.
- Titles are complete claims ("Spaced repetition makes memory a choice"), so
  linking to a title already says something.
- Prefer associative links over hierarchical folders.

Most of my notes start as fleeting notes and only some become evergreen.
