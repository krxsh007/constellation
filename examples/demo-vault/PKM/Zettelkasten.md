# Zettelkasten

Niklas Luhmann's slip-box method: thousands of small index cards, each holding
one idea, densely linked to one another.

- **Atomic notes**: one idea per note, written in your own words, so it can be
  linked from many contexts.
- Links matter more than folders. A note's value comes from its connections;
  following them surfaces unexpected combinations of ideas.
- Write the link reason, not just the link: "contradicts", "example of",
  "builds on".

The hard part is the habit of linking every new note to existing ones.
